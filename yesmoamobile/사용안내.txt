YESMOA 모바일 앱 (PWA)

현재 YESMOA의 단가표, 제품 선택·수량·예상 견적, 데이터 파기 및 매입 안내를 포함합니다.
휴대폰용 하단 메뉴, 설치 아이콘, 오프라인 저장을 추가했습니다.

미리보기: 이 폴더를 HTTP 서버로 열어 확인하세요. index.html 더블클릭만으로는 앱 설치가 되지 않습니다.
배포: 폴더 전체를 HTTPS 웹서버 또는 GitHub Pages의 yesmoamobile/ 경로에 올리세요.
Android: Chrome으로 배포 주소를 열고 ‘앱 설치’ 또는 메뉴의 ‘홈 화면에 추가’를 선택합니다.
iPhone: Safari로 배포 주소를 열고 공유 → 홈 화면에 추가를 선택합니다.
첫 방문은 인터넷 연결이 필요하며, 방문해 저장된 이미지와 단가표는 오프라인에서 다시 볼 수 있습니다.
오프라인 가격은 최신 가격이 아닐 수 있습니다.
Windows EXE 컴사양 진단은 휴대폰에서 실행되지 않습니다.

이 결과물은 홈 화면에 설치하는 웹앱입니다. APK/IPA 및 앱스토어 등록 파일은 아닙니다.
원본 outputs/YESMOA는 변경하지 않았습니다.
