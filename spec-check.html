내 컴퓨터 사양 확인

다운로드 없이,
내 컴퓨터 사양을 확인하세요.

Windows 작업 관리자에서 CPU·메모리·디스크·그래픽카드 정보를 확인하세요.
잘 모르겠다면 확인 화면을 사진으로 찍어 상담 시 보내주셔도 됩니다.

Ctrl+Shift+Esc

판매할 Windows 컴퓨터에서 세 키를 함께 눌러 주세요.

휴대폰으로 안내를 보고 있다면 판매할 컴퓨터에서 따라 해 주세요.
이 페이지는 확인 방법을 안내하며, 실제 컴퓨터 사양을 자동 조회하지 않습니다.

01 작업 관리자 열기

Ctrl + Shift + Esc를 함께 누르면 작업 관리자가 열립니다.

클릭하여 확대

왼쪽 아래 버튼을 확인하세요

‘자세히’가 보이면
눌러서 상세 화면을 열어 주세요.

‘간단히’가 보이면
이미 상세 화면입니다. 누르지 말고 02번으로 진행하세요.

이 두 버튼은 Windows 버전이 아니라 현재 보기 상태에 따라 달라집니다.

02 성능 선택

Windows 10 예시 · 이미지를 누르면 확대됩니다.

Windows 10에서는 위쪽 ‘성능’ 탭을 선택하세요.
Windows 11에서는 왼쪽의 ‘성능’ 메뉴를 선택하세요.

Windows 버전에 따라 화면과 메뉴 위치가 다를 수 있습니다.

03 부품별 확인 예시

작업 관리자 왼쪽에서 부품을 선택하고 오른쪽의 정보를 확인하세요.

아래 버튼은 안내용 예시만 전환합니다. 실제 사양은 내 컴퓨터에서 확인하세요.

Windows 10 예시 · 이미지를 누르면 확대됩니다.

CPU · 프로세서 모델명

예시: Intel Core i5-13400F

오른쪽 위 모델명을 확인하세요. 현재 동작 속도는 모델명과 다릅니다.

Windows 10 예시 · 이미지를 누르면 확대됩니다.

메모리 · 총 용량 · 속도 · 사용된 슬롯

예시: 32GB / 3200MHz / 슬롯 2/2

사용 중 용량은 총 용량과 다릅니다. 이 화면에서 DDR 규격이 표시되지 않을 수 있습니다.

Windows 10 예시 · 이미지를 누르면 확대됩니다.

디스크 · 모델명 · SSD/HDD 종류

예시: T-FORCE 512GB / SSD

제품 표기 용량과 Windows 표시 용량은 다를 수 있습니다. 디스크가 여러 개면 각각 확인하세요.

Windows 10 예시 · 이미지를 누르면 확대됩니다.

GPU · 그래픽카드 모델 · 전용 메모리

예시: NVIDIA GeForce RTX 3060 / 12GB

공유 GPU 메모리는 그래픽카드 자체 메모리와 다릅니다. GPU가 여러 개면 각각 확인하세요.

사진 속 모델과 용량은 예시이며, 고객님의 컴퓨터에서는 다른 값이 표시됩니다.

04 사진 준비와 상담

CPU·메모리·디스크·GPU 화면을 각각 사진으로 찍어 상담 시 보내 주세요.
모델명을 직접 적기 어렵다면 화면 사진만 준비하셔도 됩니다.

확인되는 정보만 준비해 주시면 나머지는 상담하면서 안내해 드립니다.
