실행이 어렵다면

Windows가 실행을 제한하나요?

이 배포 파일은 코드 서명 인증서가 없는 프로그램입니다. Windows 또는 보안 프로그램이 실행을 제한할 수 있습니다. 차단을 해제하거나 보안 설정을 낮추지 말고, 아래 Windows 기본 확인 방법을 사용하세요.

프로그램 없이 확인하는 방법

Ctrl + Shift + Esc → 작업 관리자 → 성능에서 CPU·메모리·GPU를 확인하세요. Win + R → msinfo32 → 확인으로 시스템 정보도 볼 수 있습니다.

법적·개인정보 관련 안내

타업체 코드·로고·사진을 사용하지 않고 YESMOA 전용으로 제작했습니다. 하드웨어 조회 결과는 자동 수집·전송하지 않습니다. 상담을 위해 결과를 보내는 경우에는 전달할 내용을 직접 확인하세요. 웹 호스팅 서비스의 접속 기록은 해당 서비스 정책이 적용됩니다.
