YESMOA 시세표 수정 방법

1. 웹에서 부품 매입 단가표 또는 불량 매입 단가표 카드를 클릭합니다.
2. 시세표 팝업이 열리면 오른쪽 위 X 버튼으로 언제든 원래 화면으로 돌아갈 수 있습니다.
3. 표 내용을 고치려면 편집하기 버튼을 누릅니다.
4. 바꾸고 싶은 품목명, 단위, 금액 칸을 클릭해서 글자를 수정합니다.
5. 수정 후 저장 버튼을 누르면 이 컴퓨터의 현재 브라우저에 내용이 저장됩니다.
6. 처음 값으로 되돌리고 싶으면 초기화 버튼을 누릅니다.

주의:
현재 저장 방식은 브라우저 저장 방식입니다. 즉, 내 컴퓨터에서는 수정 내용이 보이지만 다른 사람의 컴퓨터나 GitHub Pages 전체에 영구 반영되는 방식은 아닙니다.
전체 방문자에게 같은 내용으로 보이게 하려면 index.html 안의 표 글자를 직접 수정한 뒤 GitHub에 다시 업로드해야 합니다.
