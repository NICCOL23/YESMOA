단가 관리 사용 방법
1. https://yesmoa.kr/#admin 에서 기존 관리자 계정으로 로그인합니다.
2. 단가 관리를 열고 매입 단가표 또는 불량 매입 단가표를 선택합니다.
3. 품목 필터와 제품명 검색으로 제품을 찾습니다.
4. 수정할 단가에 원 단위 정수를 입력하고 해당 제품의 저장을 누릅니다.
5. 금액 미등록은 상담 견적을 체크하고 저장합니다. 0원을 입력하면 실제 0원으로 저장됩니다.
6. 저장했습니다 메시지를 확인합니다. 저장 실패 시 입력을 유지하므로 다시 저장합니다.
7. 동시 수정 충돌 안내가 나오면 입력을 메모하고 새로고침하여 최신 단가를 확인합니다.
고객 단가표는 열 때 서버 최신 단가를 조회하며, 이미 열려 있으면 최신 단가 불러오기를 누릅니다.
정상/불량 기존 1249개 제품은 가격과 EA/KG 단위를 그대로 이전했습니다.
서버 가격 관리: public.yesmoa_prices. 이력: public.yesmoa_price_history (고객 접근 불가).
SQL migration: price-management.sql (기존 ID 가격 덮어쓰기 없음).
Rollback-only server validation: price-verification.sql (테스트 가격은 커밋하지 않음).
새 제품 추가 및 이름/분류/단위 변경은 이번 관리자 화면에서 제공하지 않습니다.
